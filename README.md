## 📱 iPad'e `.ipa` Kurulumu
1. `KomiserRakun-iPad.ipa` dosyasını bilgisayarınızda **[Sideloadly](https://sideloadly.io/)** veya **[AltStore](https://altstore.io/)** uygulamasına sürükleyin.
2. iPad'inizi kablo (veya Wi-Fi) ile seçip Apple kimliğinizle `Start` butonuna basın.
3. Kurulum sonrası iPad'de *Ayarlar → Genel → VPN ve Aygıt Yönetimi* altından geliştirici profiline **Güven** deyin ve %100 çevrimdışı tam ekran oynayın!
